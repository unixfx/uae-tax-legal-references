# أداة تحويل الصوت إلى نص مع طوابع زمنية 🎙️

سكربت بايثون يستخرج الكلام من أي ملف صوتي (أو فيديو) ويحوّله إلى نص مكتوب مع تحديد توقيت بداية ونهاية كل جملة — وحتى كل كلمة — بدقة أجزاء الثانية. يعتمد على نموذج **Whisper** عبر مكتبة `faster-whisper`، ويدعم **اللغة العربية** والإنجليزية وأكثر من 90 لغة مع كشف تلقائي للغة.

## التثبيت

يتطلب Python 3.9 أو أحدث، بالإضافة إلى `ffmpeg` لقراءة الصيغ الصوتية:

```bash
# تثبيت ffmpeg (على أوبونتو/دبيان)
sudo apt install ffmpeg

# تثبيت المكتبة المطلوبة
pip install -r requirements.txt
```

> لا حاجة لبطاقة رسومية — يعمل على المعالج العادي، وعند توفر بطاقة NVIDIA يستفيد منها تلقائيًا.

## الاستخدام

أبسط استخدام (كشف تلقائي للغة، إخراج TXT + SRT + JSON):

```bash
python transcribe.py recording.mp3
```

تفريغ ملف عربي بنموذج أدق مع توقيت كل كلمة:

```bash
python transcribe.py محاضرة.m4a --model medium --language ar --word-timestamps
```

اختيار صيغ الإخراج ومجلد الحفظ:

```bash
python transcribe.py meeting.wav --formats srt vtt --output-dir ./نتائج
```

## الخيارات

| الخيار | الوصف | الافتراضي |
|---|---|---|
| `--model` | حجم النموذج: `tiny` `base` `small` `medium` `large-v3` — الأكبر أدق وأبطأ | `small` |
| `--language` | رمز اللغة (`ar`, `en`, ...) أو فارغ للكشف التلقائي | تلقائي |
| `--word-timestamps` | توقيت كل كلمة على حدة (يُحفظ في JSON) | معطّل |
| `--formats` | صيغ الإخراج: `txt` `srt` `vtt` `json` | `txt srt json` |
| `--output-dir` | مجلد حفظ النتائج | بجانب الملف الصوتي |
| `--device` | `auto` أو `cpu` أو `cuda` | `auto` |

## نماذج الإخراج

**SRT** (يصلح كترجمة فيديو مباشرة):

```
1
00:00:00,000 --> 00:00:04,320
بسم الله الرحمن الرحيم، أهلاً بكم في هذا الشرح

2
00:00:04,320 --> 00:00:09,150
سنتحدث اليوم عن ضريبة الشركات في دولة الإمارات
```

**JSON** (مع `--word-timestamps`):

```json
{
  "segments": [
    {
      "id": 1,
      "start": 0.0,
      "end": 4.32,
      "text": "أهلاً بكم في هذا الشرح",
      "words": [
        {"word": "أهلاً", "start": 0.0, "end": 0.54},
        {"word": "بكم", "start": 0.54, "end": 0.92}
      ]
    }
  ]
}
```

## نصائح للدقة

- للعربية الفصحى واللهجات: النموذج `medium` أو `large-v3` يعطي أفضل النتائج.
- الأداة تستخدم فلتر VAD تلقائيًا لتجاهل فترات الصمت وتحسين دقة التوقيت.
- الصيغ المدعومة: mp3, wav, m4a, ogg, flac, aac, wma وحتى ملفات الفيديو mp4/mkv.
